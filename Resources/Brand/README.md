# Brand assets

The current app icon is the gray Dianlian horn spirit. Its canonical Icon Composer source and static export live in `assets/brand/`. See `assets/brand/README.md` for the update workflow.

`logo.png` and `AppIcon-Default.png` are documentation copies of the approved Composer export. `build.sh` compiles the adaptive catalog from `assets/brand/kururu.icon` and generates the legacy ICNS fallback from `assets/brand/AppIcon-Default.png`.

The historical `AppIcon.icon` in this directory is an unused reference, not a build input. Archived mascot studies under `assets/mascots/` are not app icons.
