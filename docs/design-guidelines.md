# kururu 设计规范

新增功能、调整设置页或面板、改文案之前先读这份文档。改动引入新规则时写进来；规则变了就改原条目，不并列新旧两版。控件规则以 [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) 为准，偏离时在这里写明理由。

## 1. 功能与入口

- **E1 功能库管启用。** 功能库的「启用 / 关闭」决定一个功能是否存在：关掉会释放资源、保留设置。功能页里的开关只管这个功能内部的具体行为。
- **E2 设置放在用户会去找的地方。** 位置跟随 macOS 系统设置的习惯，而不是代码归属。例如键盘背光快捷键放在「键盘」页，尽管它属于「显示器」功能。
- **E3 面板显示在「菜单栏面板」设置页管理。** 菜单栏面板里每一项是否显示，都能在这一页设置，面板的编辑模式写同一个值。

## 2. 设置页结构

- **S1 用原生分组表单。** 页面用 `SettingsForm`（`Form` + `.formStyle(.grouped)`），分区用 `SettingsSection`。
- **S2 分区即层级。** 需要分组就开新分区并写标题，不用粗体文字、分隔线或卡片在分区里假装子标题。
- **S3 分区里不放 `Divider()`。** 表单会把它当成一行，渲染成空白行。行与行之间表单自己会分隔。
- **S4 表单行里不嵌卡片。** 不给行加背景、边框或圆角容器。提示信息用说明文字，警告用橙色说明文字。
- **S5 说明文字只写用户需要的信息。** 一句话写完；次要解释放进标题旁的问号；不写复述标题的说明。

## 3. 控件

依据 HIG「Toggles」一节。

- **C1 表单里单独一行的设置用行内开关，不手动指定尺寸。** 分组表单里行内开关的尺寸由系统决定，2026-09 在 macOS 27 上实测手动设 `.mini` 不改变渲染。
- **C2 控制一组设置的主开关用常规尺寸开关。** 需要显式写 `.controlSize(.regular)`，否则会和行内开关一样大。它下面的子设置在它关闭时变灰（见 C5）。
- **C3 勾选框用于多选和紧凑视图。** 从一组里选若干项（输出设备、URL 参数、菜单栏指标、清理项目）用勾选框。菜单栏面板的紧凑视图用勾选框。已经是勾选框的多选列表不改成开关。
- **C4 互斥选项不用多个开关。** 两个及以上互斥的选项用单选按钮或弹出菜单，不用几个开关互相关掉。
- **C5 子设置跟随父开关变灰，不隐藏。** 用户可以先看到并设好，再打开父开关。
- **C6 删掉旧控件时一起删残留。** 空标题、失去控件的说明、不可达的分支一并删除。

## 4. 术语（简体中文）

| 编号 | 语义分工 |
|---|---|
| T1 | Copy 用「拷贝」，Duplicate 用「复制」，名词 a copy 用「副本」 |
| T2 | 文件导出用「存储」，内部设置、条目和预设用「保存」，容量用「存储空间」 |
| T3 | App、Dock 保留英文；苹果系统专名按用户需要寻找的名称保留，如「应用程序」「活动监视器」 |
| T4 | 可关闭模式用「启用」，更改起作用用「生效」，安装版本用「安装」。参数提交与二次确认分别用「确定」「确认」 |
| T5 | 中文句子中的 App 名可用引号标明，参数列表不按 App 名处理 |
| T6 | 系统授权索要管理员密码的场景用「您」，普通应用说明用「你」，不要全局替换 |
| T7 | 「三指中键」「窗口切换器」「『音乐』App」按对象与行为命名。系统指标用「监控」，输入事件用「监听」 |
| T8 | 功能启停与软件安装卸载分开，不能因为旧字段叫 install 就在界面写「安装」 |
| T9 | 页面标题用中文名时，说明文字引用同一个名字，如「Dock 窗口预览」，不在说明里改回英文 |

词义依赖对象和上下文，不做全库批量替换。

## 5. 判断标准

- **J1 算缺陷：** 设置和实际行为不一致；设置在某种功能组合下找不到；同一处出现重复控件；违反本文件规则。
- **J2 算行为：** 按系统约定工作（如温度阈值按摄氏存储）；各页面按自身职责调用外部工具；代码注释写明理由的特殊控件（如拖动排序列表里不用原生开关）。

## 6. 待定

- **P1 页面总开关。** 是否在功能页顶部重复功能库的启用开关，以及切换器、暂存架、径向菜单等页内第二层总开关如何处理，暂缓。
- **P2 重复入口。** 同一设置出现在多处时留哪一处：菜单栏指标开关、监控页的菜单栏与面板分区、剪贴板和 URL 清理页的「在面板中显示」。
- **P3 分段切换内容。** 屏幕捕捉、媒体、清理、环境、功能库五页用分段控件切换整块内容。屏幕捕捉页按流程重排的方案（共用在上、各工具结果分区）试过后否决，保持工具切换；其余页面待定。
