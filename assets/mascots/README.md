# Kururu mascot assets

章鱼是 kururu 0.1.0 的正式标识，原生静态几何用于菜单栏、界面与应用图标。SVG、PNG 与原生实现采用一致的大头比例。HTML/JavaScript 动画仍是视觉参考，未接入应用运行时。小猫保留为独立造型研究。

| 角色 | 静态素材 | 动态预览 | 状态 |
|---|---|---|---|
| 章鱼 | [SVG](octopus/mark.svg) · [PNG](octopus/mark.png) | [预览入口](octopus/index.html) | 已确认造型：D4 排布、圆腕尖、浅腕间蹼、平滑身体接缝 |
| 小猫 | [SVG](cat/mark.svg) · [PNG](cat/mark.png) | [预览入口](cat/index.html) | 基于猫头动态版，补充眼睛/鼻子的轮廓边界保护 |

下载或克隆仓库后，在浏览器打开对应 `index.html`。GitHub 文件页展示源码，不直接运行 HTML。也可从本目录执行 `python3 -m http.server 8080`。

## 动作与交互

章鱼：安静、开心、寻找、挠头、捂脸、收腕休息、模拟高负载。寻找沿用原版上侧探查；高负载是倒立后沿纵轴旋转的手动演示，未读取真实 CPU/GPU。腕间蹼开关用于查看连接结构。

小猫：安静、好奇、思考、寻找、开心、打瞌睡、惊讶、怀疑；另有跳跃回弹、转身和眨眼。保留原猫头版本的表演，不套用章鱼腕足动作。

两者均支持深浅背景、页面内视线联动、拖拽、暂停和小尺寸预览。遵循系统减少动态效果，评审时可显式勾选“本页播放完整动效”。隐藏页面或暂停时停止动画刷新。预览的持续巡演不代表产品默认行为。

## 验证记录（2026-09-09）

小猫在八种状态下共模拟 640 帧，加入左右转头及视线极值。逐帧对可见眼睛和鼻子各采样 32 个路径点，转换到头部坐标后检测 SVG 填充区域，越界计数为 0，弹簧数值均有限。另以随头部更新的 SVG 裁切轮廓作为边界保护。此结果是离散采样检查，不等于穷尽所有输入。

两份脚本通过语法检查，HTML 本地链接均可解析。静态素材已逐张目视检查，PNG 为 512 × 512 透明背景。此次只验证浏览器资源，未构建 Swift 应用。

## 来源与范围

造型与动画由本项目独立编写，研究了 [Grok icon study](https://github.com/blessonism/grok-icon-study) 的弹性过渡和眼形插值思路；此目录不包含该参考项目提取的角色资产。历史对比方案、旧视频和桌面讨论文档不在本资源包内。
